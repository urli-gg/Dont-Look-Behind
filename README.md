# Don't Look Behind · Nightmare Update

Terror de exploración en el Hotel Umbral. El perfil inicial **Pesadilla** usa iluminación fría, eventos que varían entre partidas y persecuciones sensibles al progreso. Sal del ascensor, encuentra los cuatro sellos numerados y abre la persiana de salida. Cuando la criatura se acerque, mirarla de frente le hará retroceder. Tienes tres oportunidades.

## Jugar

1. Abre el proyecto con Unity `6000.3.19f1`, carga `Assets/Scenes/GameScene.unity` y pulsa Play en el Editor.
2. Pulsa **Play / Jugar** dentro de la cabina. El panel permite ajustar el audio, la dificultad, los sustos y el tipo de giro.
3. En VR, muévete con el joystick izquierdo y gira con el derecho. El giro inicial es por pasos de 30°. Empuja el joystick derecho hacia delante para apuntar a las zonas de teletransporte. Apunta a los botones con cualquiera de los mandos y pulsa el gatillo. Usa el botón de agarre para recoger objetos y suéltalo con movimiento para lanzarlos.
4. En Windows sin visor, usa **WASD**, el ratón para mirar, **E** o clic izquierdo para activar y agarrar, **E** para soltar y clic derecho para lanzar. **Esc** libera el cursor.

La compilación de Windows se genera en `Builds/HotelUmbral`. Conserva junto al ejecutable los archivos que Unity genera en esa carpeta.
