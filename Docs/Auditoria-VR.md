# Auditoría y orden de implementación

La rama `feature/vr-professional-overhaul` parte de `c6bc180` (`Elevador Agregado`), que coincidía con `origin/main` y con la cabeza publicada. El directorio de trabajo estaba limpio. El historial inmediato contiene el elevador, el susto ambiental y las escenas de resultado.

El proyecto usa Unity `6000.3.19f1` (`7689f4515d75`), URP `17.3.0`, XR Interaction Toolkit `3.5.1`, OpenXR `1.17.1`, Meta OpenXR `2.5.1` e Input System `1.19.0`. XR Management configura OpenXR y el proyecto incluye perfiles de control para Touch y Touch Plus. Las escenas del ejecutable son `GameScene`, `GameOver` y `WinScene`. `MainMenu`, `BasicScene`, la copia de `GameScene` y las escenas de muestras quedan fuera del recorrido principal.

- **Escena y assets.** El corredor usa `PASILLO.mtl.obj` con elementos arquitectónicos agrupados y colliders auxiliares independientes. También contiene un entorno XR de plantilla, una zona de teletransporte de muestra y texturas de origen de 4K/8K. Se conserva el modelo fuente y la copia de la escena para referencia. `GhostGirl`, `BloodNumber`, el elevador, el canvas y el teclado se inventariaron antes de intervenir.
- **Flujo.** El script de viaje existe en Git como `ElevatosSequence.cs`, aunque la clase se llama `ElevatorSequence`. El menú llama a esa secuencia por referencia serializada. La apertura interpola dos hojas, con distancias locales compartidas y sin un enlace físico garantizado al corredor. La activación de la criatura depende de un trigger y de la etiqueta `Player`.
- **Juego.** `Creature` usa el ángulo horizontal, tres miradas de hasta tres segundos, traslación directa y carga inmediata de `GameOver`. No había prueba de línea de visión ni navegación entre obstáculos. `JumpscareTrigger` ya gestiona una aparición ambiental independiente. El código se genera al iniciar, presupone cuatro referencias válidas e imprime la solución. El teclado tiene estado de error y el portón habilita la victoria al empezar a abrirse.
- **VR y rendimiento.** Hay configuraciones URP de rendimiento y calidad. La de rendimiento venía con luces adicionales desactivadas, un problema para la nueva iluminación localizada. El equipo dispone de una RTX 3060 y del Editor de Windows de la versión exacta con soporte de compilación Windows. La presencia de esos componentes no acredita pruebas de visor, Android o rendimiento VR.

El orden de trabajo es cerrar el recorrido físico del elevador y el hotel, fijar arte y luz, integrar interacción y rotura, conectar sonido y criatura, añadir captura y ajustar los resultados y la validación de extremo a extremo.
